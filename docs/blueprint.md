# **App Name**: DerivEdge

## Core Features:

- API/Deriv Login: Allow users to log in using their Deriv API key or Deriv account authentication.
- Dashboard: Display the last 26 ticks and extract and display all volatility markets available on Deriv.
- Trade Parameters: Allow users to input trade parameters such as multiplier, take profit, and stop loss.
- Trade History: Display a table of the user's recent trade history.
- AI Analysis Configuration: Allow users to select the number of ticks for analysis (25, 50, 75, 100).
- Market Selection: Allow users to select market types (e.g., volatility indices) and contract types (even/odd, over/under, matches/differs).
- AI-Powered Anomaly Detection Tool: Analyze the selected number of recent ticks based on user-selected contract type (even/odd, over/under, matches/differs) to identify potentially profitable anomalies. For example, highlight odd numbers that have not appeared within the last 25 ticks and present these anomalies as trading opportunities.

## Style Guidelines:

- Primary color: Deep blue (#2962FF) to evoke trust and reliability in the financial context.
- Background color: Light gray (#F0F2F5) to provide a clean and neutral backdrop.
- Accent color: Teal (#64FFDA) to highlight key interactive elements and calls to action.
- Body and headline font: 'Inter', a sans-serif font, for a clean and modern user experience.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use minimalistic, professional icons related to trading and analysis.
- Use subtle transitions and animations for a smooth user experience.
